# Contribuir a la documentación

- Toda imagen debe guardarse en `images/` y citarse con Markdown relativo desde el documento donde se explica.
- Cada evidencia debe distinguirse de los diagramas conceptuales e indicar si es histórica o una prueba nueva.
- No se aceptan pantallazos recreados para aparentar un resultado real.
- No publiques contraseñas, secretos RADIUS, `enable secret`, hashes, claves privadas ni exports NPS sin saneamiento.
- Antes de cambiar configuración, conserva un respaldo local privado y documenta el resultado real.
- Los comandos del repositorio deben usar los datos ya conocidos; los secretos se introducen de manera interactiva.
